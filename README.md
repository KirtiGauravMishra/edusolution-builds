# EduSolution — Android builds

Test builds for the EduSolution Android app. **This repository holds APKs only** —
the application source lives in a separate private repository.

## Install

1. Open the [latest release](../../releases/latest) on your Android phone
2. Download the `.apk`
3. Open it — Android will ask you to allow "Install unknown apps" for your
   browser the first time

## Notes

- These are **release builds, not Expo Go** — push notifications, biometric
  unlock and offline detection all work.
- All content is demo data. There is no backend yet, so nothing syncs between
  devices and state resets if you clear app storage.
